# 菜品銷售紀錄系統

只記錄每天賣了哪些菜、各幾份，並看每日／每月合計（可匯出 Excel）。同一份網頁 `web/` 同時是 PWA 與 Windows 桌面版的介面。

v2.0.0 起簡化：拿掉售價、成本、毛利與統計圖表。資料格式與雲端後端沒變（舊版資料、試算表的售價／成本欄位都保留），新舊版可以同時連同一個雲端。

## 功能
- **📝 每日紀錄**：選日期，逐道菜輸入份數（＋／−、Enter 跳下一道），顯示本日總份數、各分類份數；可寫備註、帶入上次份數、直接新增菜品。每道菜可按 ⏱ 記下幾點賣完；每筆會記下最後是誰、幾點改的（本日修改紀錄）。
- **📅 每月合計**：月曆顯示每天總份數（點日期回到當天紀錄）、本月總份數／有記錄天數／平均每天、各菜品本月合計，並和上月或去年同月比較增減（本月還沒過完時只比到同一天）；可匯出本月 Excel（每日銷量明細、菜品合計），或存成一頁 A4 的月報 PDF（月曆、星期平均、菜品排行、備註）。
- **🧾 備料分析**：備料預估（依過去 4／6／8 個同一個星期幾的平均份數，可多備 10%／20%，算出每道菜建議備量（有標記賣完的日子份數多算 20%），可存成備料單 PDF，留有「實際備」「賣完時間」欄位手寫）；星期分析（最近 4／8／12 週每個星期幾平均賣幾份、各菜品星期熱度表，公休日不計）。
- **📈 進階分析**（期間 4／12 週／半年；可存成兩頁的分析報告 PDF）：
  - 預估準確度：過去 4 週的預估和實際賣出對照，列出常估太多、太少的菜，建議安全量，可開啟「依每道菜誤差自動修正」（最多 ±30%，設定存在這台裝置）。
  - 菜單結構 ABC：前 80% 銷量的主力菜、墊底可汰換的菜；有單價時顯示營業額。
  - 趨勢警示：最近 4 週和前 4 週比，標出成長、衰退，以及最近 7 天突然下滑的菜（附 8 週小長條）。
  - 售完損失：用之前同星期幾沒賣完的日子推估少賣幾份、少賺多少，以及平均幾點賣完。
  - 新菜上市追蹤：前 4 週和同分類舊菜比，判斷表現好、普通或偏弱。
  - 互相排擠：扣掉星期幾和長期趨勢後，找出「一道賣得好、另一道就賣得差」的組合。
  - 年度走勢：最近 12 個月和去年同月比（用每天平均），標出旺季、淡季。
  - 特殊日影響（v2.5）：每天可以標註雨天、颱風、連假、活動等（也能自訂），自動算出每種日子多賣或少賣幾 %、哪些菜受影響最大；預估的日子先標註，備料預估會乘上影響倍數。
  - 剩餘與報廢（v2.5）：每日紀錄打開「♻ 記錄備量」，每道菜多填「做了幾份」，就能算剩下多少、報廢率、報廢成本（有設成本時），並建議每道菜要多備或少備。備料分析可以「📥 填入當天備量」直接帶入建議量。
  - 目標達成（v2.5）：設定每天、每月和各菜品的目標份數，顯示達成率，並照星期幾平均推估月底能不能達成。
  - 分店比較（v2.5）：加入其他分店的雲端（只讀取）或 JSON 備份，比較每天平均、成長、熱賣菜、報廢率和最近 6 個月走勢；分店清單只存在這台裝置。
  - 分析報告 PDF 共三頁。
- **📧 自動週報**（v2.5，需要雲端同步）：每週一早上 8 點由 Apps Script 把上週摘要寄到指定 Email。第一次使用要在試算表的 Apps Script 編輯器執行一次 `setupReport()` 授權寄信。
- **⚙️ 菜品與設定**：店名、這台裝置的使用者名稱、鎖定過去的紀錄（只能改最近 1／3／7 天，主管密碼解鎖）、銷售目標、自動週報、菜品清單（名稱、分類、售價、成本、停售、排序、刪除）、雲端同步、JSON 備份／還原、清除。
- **☁ Google 雲端同步**：資料存在 Google 試算表（分頁：菜單、銷售、備註；銷售分頁最後三欄是售完時間、輸入者、備量，備註分頁最後一欄是特殊日標註），手機與電腦共用。每筆資料以修改時間合併，離線時先存本機、連上網路再上傳；在試算表手動修改也會同步回 App。後端在 `cloud/Code.gs`（clasp 管理），預設網址在 `web/config.js`。

## 使用
- 桌面版：`dist\菜品銷售紀錄.exe`，資料存在 `%APPDATA%\DishSales\data.json`（每天自動備份到 `backups\`，保留 30 份）。
- PWA：把 `web/` 放到任何 https 網站（例如 GitHub Pages），手機用瀏覽器開啟後「加入主畫面」。資料存在該瀏覽器的 IndexedDB。

## 開發
```
python make_icons.py      # icon.svg → PNG / ico
python build.py           # 打包 dist\菜品銷售紀錄.exe
```
自我測試：設定 `DISHSALES_DATA=<資料夾>`、`DISHSALES_SELFTEST=<結果.json>`、`DISHSALES_EXPORT_DIR=<匯出資料夾>` 後執行 exe，會自動操作、匯出 Excel、寫出結果並關閉。
